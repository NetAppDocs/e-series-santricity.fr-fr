= Afficher les paramètres du contrôleur dans SANtricity System Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez afficher des informations sur un contrôleur, telles que l'état des interfaces hôtes, des interfaces de lecteur et des ports de gestion.

.Étapes
. Dans le panneau de gauche, sélectionnez menu:Hardware[Controllers and components].
. Effectuez l'une des actions suivantes pour afficher les paramètres du contrôleur :
+
** Cliquez sur le contrôleur pour afficher le menu contextuel, puis sélectionnez *Paramètres d'affichage*.
** Sélectionnez l'icône du contrôleur (en regard de la liste déroulante *Shelf*). Pour les configurations duplex, sélectionnez *contrôleur A* ou *contrôleur B* dans la boîte de dialogue, puis cliquez sur *Suivant*.
+
Le menu coulissant des paramètres du contrôleur s'ouvre.



. Consultez les sections pour passer d’un paramètre de propriété du contrôleur à un autre.
+
.Détails du champ
[%collapsible]
====
[cols="25h,~"]
|===
| Section | Description 


 a| 
Détails
 a| 
Affiche l'état du contrôleur, la date/l'heure, le nom du modèle et le numéro de pièce de rechange.



 a| 
Configuration actuelle
 a| 
Affiche la version actuelle du firmware et la version de la NVRAM.



 a| 
Cache de données
 a| 
Affiche les totaux du cache de données.



 a| 
Modules de cache de données
 a| 
Affiche l'emplacement, l'état et la capacité du module cache.



 a| 
Cache du processeur
 a| 
Affiche le total du cache du processeur.



 a| 
Dispositifs de sauvegarde du cache
 a| 
Affiche l'emplacement, l'état et la capacité du périphérique de sauvegarde du cache.



 a| 
Interfaces d'hôte
 a| 
Affiche les informations de l'interface d'hôte et l'état de la liaison pour chaque port.



 a| 
Interfaces de lecteur
 a| 
Affiche les informations d'interface du lecteur et l'état de la liaison pour chaque port.



 a| 
Paramètres du port de gestion
 a| 
Affiche les détails du port de gestion, notamment le nom d'hôte du contrôleur, la connexion à distance et les paramètres réseau IP.



 a| 
Paramètres du serveur DNS (domain name system)
 a| 
Affiche la configuration DNS, le serveur DNS principal et le serveur DNS de secours.



 a| 
Paramètres du serveur Network Time Protocol (NTP)
 a| 
Affiche les détails de configuration du service NTP et du serveur NTP.

|===
====
. Cliquez sur *Fermer*.
