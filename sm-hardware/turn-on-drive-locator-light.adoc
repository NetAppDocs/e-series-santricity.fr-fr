= Activer un voyant de localisation de lecteur dans SANtricity System Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
À partir de la page matériel, vous pouvez activer le voyant de localisation pour trouver l'emplacement physique d'un lecteur dans la matrice de stockage.

.Description de la tâche
Vous pouvez localiser des lecteurs uniques ou multiples affichés sur la page matériel.

.Étapes
. Dans le panneau de gauche, sélectionnez menu : Hardware[Drives].
. Pour localiser un ou plusieurs lecteurs, effectuez l'une des opérations suivantes :
+
** *Disque unique* -- Sur le schéma de l’étagère, repérez le disque que vous souhaitez positionner physiquement dans la baie. Cliquez sur le disque pour afficher son menu contextuel, puis sélectionnez *Activer le voyant de localisation*.
+
Le témoin de localisation du lecteur s'allume. Une fois le lecteur physiquement localisé, revenez à la boîte de dialogue et sélectionnez *Désactiver*.

** *Plusieurs lecteurs* – Dans le champ de filtre, sélectionnez un type de lecteur physique et un type de lecteur logique. Le nombre de lecteurs correspondant à vos critères s'affiche complètement à droite du champ. Ensuite, cliquez sur *Activer les voyants de localisation*. Lorsque vous avez localisé physiquement les lecteurs, revenez à la boîte de dialogue et sélectionnez *Désactiver*.
