= En savoir plus sur la surveillance des volumes légers dans le logiciel SANtricity
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez surveiller les volumes fins en termes d'espace, puis générer des alertes appropriées pour éviter les conditions de capacité insuffisante.

Les environnements à provisionnement fin peuvent allouer plus d'espace logique que leur espace de stockage physique sous-jacent. Vous pouvez sélectionner le menu : Stockage [Surveillance des volumes fins] pour surveiller la croissance de vos volumes fins avant qu'ils n'atteignent la limite maximale de capacité allouée.

Vous pouvez utiliser la vue surveillance fine pour effectuer les opérations suivantes :

* Définissez la limite de capacité allouée à laquelle un volume fin peut se développer automatiquement.
* Définissez le pourcentage auquel une alerte (seuil d'avertissement dépassé) est envoyée dans la zone de notifications, accessible via l'icône de cloche dans le coin supérieur de la fenêtre, lorsqu'un volume mince est proche de la limite de capacité maximale allouée.


Pour augmenter la capacité d'un volume fin, augmentez sa capacité indiquée.

[NOTE]
====
System Manager ne propose pas d'option pour la création des volumes fins. Si vous souhaitez créer des volumes fins, utilisez l'interface de ligne de commande (CLI).

====
[NOTE]
====
Les volumes minces ne sont pas disponibles sur le système de stockage EF80, EF50, EF600/EF600C ou EF300/EF300C.

====
