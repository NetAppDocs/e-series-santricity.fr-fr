= Afficher les données de performances graphiques dans SANtricity System Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez afficher les données de performances graphiques pour les objets logiques, les objets physiques, les applications et les workloads.

.Description de la tâche
Les graphiques de performances affichent des données historiques ainsi que des données en temps réel actuellement capturées. Une ligne verticale sur le graphique, appelée mise à jour en direct, distingue les données historiques des données en temps réel.

*Vue du tableau de bord*

Le tableau de bord contient un graphique affichant les performances au niveau de la baie de stockage. Vous pouvez sélectionner des indicateurs limités dans cette vue, ou vous pouvez cliquer sur *Afficher les détails des performances* pour accéder au menu : Monitoring[Performance] et sélectionner tous les indicateurs disponibles.

*Vue détaillée*

Les graphiques disponibles sur la page Performance sont basés sur vos sélections :

* *Types d'objets* -- Sélectionne les catégories d'objets à inclure (par exemple, baie de stockage, contrôleurs, pools et groupes de volumes, applications, charges de travail, volumes, canaux et disques).
* *Objets* -- Sélectionne jusqu'à cinq objets spécifiques pour les types d'objets sélectionnés.


.Étapes
. Sélectionnez le menu : Surveillance [Performance].
. Utilisez les options *Types d'objets* et *Objets* pour sélectionner les données à afficher. Vous pouvez sélectionner jusqu'à cinq objets ; utilisez le champ de recherche de la liste *Objets* pour trouver des noms d'objets ou des noms partiels.
+
Toutes les métriques ne sont pas disponibles pour chaque type d'objet. Les baies de stockage et les contrôleurs ne signalent pas la latence, seuls les contrôleurs signalent le taux d'utilisation du processeur, et seuls les contrôleurs et les canaux signalent la marge de sécurité.

. Utilisez *Plage de dates* pour sélectionner la période que vous souhaitez afficher.
. Cliquez sur *Actualiser*.
. *Facultatif :* Sur un graphique individuel, utilisez *Comparer* pour superposer un autre type de métrique pour les mêmes objets.
. Si nécessaire, utilisez les options supplémentaires pour afficher les données de performances.
+
.Ou des options supplémentaires
[%collapsible]
====
[cols="25h,~"]
|===
| Option | Description 


 a| 
Plage de temps
 a| 
Sélectionnez la durée que vous souhaitez afficher (5 minutes, 1 heure, 8 heures, 1 jour, 7 jours, ou 30 jours). La valeur par défaut est 1 heure.


NOTE: Le chargement des données de performance sur une période de 30 jours peut prendre plusieurs minutes. Ne quittez pas la page web, ne l'actualisez pas et ne fermez pas le navigateur pendant le chargement des données.



 a| 
Détails du point de données
 a| 
Passez le curseur de la souris sur le graphique pour afficher les mesures d'un point de données particulier.



 a| 
Barre de défilement
 a| 
Utilisez la barre de défilement située sous le graphique pour afficher une période antérieure ou ultérieure.



 a| 
Barre de zoom
 a| 
Sous le graphique, faites glisser les poignées de la barre de zoom pour effectuer un zoom arrière sur une plage de temps. Plus la barre de zoom est large, moins les détails du graphique sont détaillés.

Pour réinitialiser le graphique, sélectionnez l'une des options d'intervalle de temps.



 a| 
Glisser-déposer
 a| 
Sur le graphique, faites glisser le curseur d'un point dans le temps vers un autre pour effectuer un zoom avant sur une plage de temps.

Pour réinitialiser le graphique, sélectionnez l'une des options d'intervalle de temps.

|===
